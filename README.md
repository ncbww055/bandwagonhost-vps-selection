## 机房与线路怎么选：CN2 GIA、CN2 和普通线路的差别

线路决定你在国内访问这台 VPS 的体验，对多数人来说比 CPU 内存更能影响使用感受。

普通国际线路（KVM 常规系列）白天速度正常，晚高峰延迟波动明显。练手、跑定时任务、部署不面向国内用户的服务，够用。CN2 是电信优化线路，比普通线路好一档，但晚高峰仍可能拥堵。CN2 GIA 是中国电信等级最高的国际专线，去程回程双程优化，三网直连，到洛杉矶的延迟稳定在 150ms 左右且晚高峰波动小。搬瓦工在洛杉矶有两个 CN2 GIA 数据中心（DC6、DC9），共 8 条 10Gbps CN2 GIA 链路，这是它家最核心的竞争力，也是 GIA-E 系列比同配置 KVM 贵的原因。

选机房前记住两条规则：

1. **GIA-E 套餐可在 11 个机房之间免费互迁**，包括美国 DC6/DC9、日本大阪软银、荷兰 9929 等。先随便选一个，用着不满意再迁，相当于一份钱买了一批机房的选择权。
2. **香港和日本特惠套餐不可迁移**，买之前想清楚位置。这两个系列贵在物理距离：香港到大陆延迟通常 30–60ms，东京稍高，都远低于美西的 150ms 以上。

还有一条隐藏规则值得单独说：**KVM/CN2 系列迁到 CN2 线路机房时，月流量按 1/3 计算**。1TB 流量的套餐迁过去，实际只剩约 333GB。这个限制在购买页上并不显眼，不少人迁移之后才发现流量缩水。如果你有迁移打算，优先考虑本来就是 CN2 或 GIA-E 系列的套餐，规则更简单。
